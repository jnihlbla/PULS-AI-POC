# IMS Metadata

Metadata specific to IMS transactions, PSBs, and programs. Not generated from SOPLIB; complements `PSB/`, `DBD/`, `MFS/`, and `Cobol/` in this repository.

## Files

- `transactions.jsonl`: IMS trancode-to-PSB-to-program mapping. Fields: `trancode`, `psb_name`, `program_name`.

`program_name` is derived as `psb_name + "00"` (all IMS programs are COBOL). The same derivation rule applies to MFS member names (see the repository root `.github/copilot-instructions.md` naming-conventions section), though there is no separate MFS metadata file — the rule is cheap to apply on the fly (position 3 of the 6-character MFS name is a language indicator; replacing it with `0` gives the PSB name).

## Provenance

Transcribed from the mainframe IMS transaction/PSB list (trancode, PSB name pairs), not generated by a script against the SOPLIB extract. A regeneration script exists outside this repository; regenerate this file if the source list changes.
